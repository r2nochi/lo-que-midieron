# Lo Que Midieron

Sitio estático con las fichas de los estudios publicados en [@loquemidieron](https://x.com/loquemidieron).

No necesita compilación: abre `index.html` o publícalo en cualquier hosting estático.

Cada ficha tiene un ancla (`#ingreso`, `#moral`, `#citas`) para enlazarla desde el último post de un hilo.

`marca/` contiene la portada (1500×500) y el avatar (800×800), con su HTML de origen.
